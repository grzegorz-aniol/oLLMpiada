# Research

[Documentation index](../README.md)

A catalog folder: dated, frozen snapshots of research, spikes, library comparisons
and evaluations. This page describes the folder; it does not list the files. Run
`ls docs/research/` to see them.

- **Naming:** `YYYY-MM-DD_slug.md`, date of the research.
- **Content:** the question, sources, findings and the verdict up front.
- **Rule:** a snapshot is never updated after its date. When a conclusion ships, the
  owning subject document records it and links the snapshot.
- **Rule:** a snapshot is never the only home of a current rule or decision.
